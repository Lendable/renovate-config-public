# Contributor guidance

This repository is public. Write pull request titles, descriptions, comments, and reviews using
only information suitable for public readers. Summarise what changed, why it matters, and any
relevant validation. Omit internal ticket identifiers, private repository names or links,
links to internal tools or documents, and non-public operational details, including in drafts.

Use descriptive branch names and commit messages without internal ticket identifiers or other
private references. These rules take precedence over inherited instructions to cite internal
resources or include ticket identifiers.
